# 项目：RAG 求职作品集 Agent

这是一个基于检索增强生成的求职作品集 Agent。访客可以浏览我的经历，并向内置 Agent 提问，Agent 会基于真实资料回答问题，而不是凭空编造。

## 后端架构

后端使用 Python 3.12、FastAPI 和 LangGraph 构建。整个问答链路用 LangGraph 的 StateGraph 编排，先对问题做向量化，再检索相关片段，最后调用大模型生成回答。这样每一步都可以单独观测、单独替换，也方便后续加入缓存和重试。

## 向量检索

检索使用 PostgreSQL 的 pgvector 扩展，把问题和文档片段都编码成向量，通过余弦相似度召回最相关的五个片段。文档表包含正文、向量和结构化元数据，方便按来源、类型和更新时间进行过滤。检索结果会连同来源一起返回给前端展示。

## 可观测性

所有大模型调用都经过 Langfuse 记录，包括输入、输出、耗时和错误状态。这样可以对每次问答做全链路追踪和分析，快速发现检索或生成环节的问题，也便于后续做线上评估和回归对比。

## 流式交互

后端提供 SSE 流式接口，事件类型包括步骤、来源、token、完成和错误。前端用 Next.js 的 ReadableStream 逐字渲染回答，同时把检索步骤和来源折叠展示给用户，避免长时间白屏，也能让用户看到回答依据。

## 评测体系

项目建立了离线评测集，包含三十个问题和期望来源，用 Hit@K、Recall 和 MRR 评估检索质量。还实现了固定长度切块和语义切块两种策略，通过对比实验用数据决定最终方案，而不是凭感觉选择参数。

## 部署方式

服务通过 Docker Compose 编排，包含 PostgreSQL、后端和前端三个组件。后端在容器里运行，依赖通过 pip 安装；开发环境则用 uv 管理 Python 3.12，前端用 pnpm 管理依赖。整个流程可以在本地一键拉起。
